# Bundled font provenance

Noto Sans Arabic, downloaded unmodified from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/notosansarabic

File: NotoSansArabic[wdth,wght].ttf (stored locally as NotoSansArabic.ttf).
License: SIL Open Font License 1.1, included in OFL.txt.
The family alias NovaArabic in pubspec.yaml does not modify the font itself.
Bundling avoids a runtime dependency on external Arabic fallback-font downloads.
