# NOVA — نسخة تطوير أولية

تطبيق Flutter بالعربية والإنجليزية للتعارف بنية واضحة. **هذه بداية تنفيذ فعلية قابلة للبناء، وليست النسخة الكاملة أو جاهزة للإطلاق التجاري.** الاسم مؤقت ولم يُفحص توفره القانوني.

تم إنشاء Android وiOS والويب داخل هذا المجلد، دون مشروع فرعي. واجهات التطبيق تستخدم Supabase فعليًا عند توفير الإعدادات؛ لا توجد حسابات أو علاقات أو رسائل إنتاج وهمية. من دون الإعدادات تظهر شاشة تشرح المطلوب.

## افتح التطبيق الآن

داخل PowerShell في هذا المجلد:

```powershell
.\scripts\run.ps1
```

أو:

```powershell
& 'C:\src\flutter\bin\flutter.bat' run -d chrome --web-port 3000
```

للتسجيل والبيانات الحقيقية، يلزم مشروع Supabase وتطبيق ملفات قاعدة البيانات. انسخ `config/local.example.json` إلى `config/local.json` وأدخل عنوان المشروع والمفتاح العام، ثم:

```powershell
& 'C:\src\flutter\bin\flutter.bat' run -d chrome --web-port 3000 --dart-define-from-file=config/local.json
```

**لا تضع service-role أو كلمات مرور قاعدة البيانات أو مفاتيح الدفع في التطبيق.** تعليمات الإعداد خطوة بخطوة، وروابط العودة، وإنشاء أول مسؤول، وإصدارات Android وiOS موجودة في [دليل التشغيل](docs/deployment.md).

## المنفذ حاليًا

- تصميم داكن وفاتح، عربية RTL وإنجليزية LTR، تنقل متجاوب ومسارات ويب.
- تسجيل ودخول بالبريد وكلمة المرور، تأكيد البريد والاستعادة، تسجيل الخروج، وإقرار العمر والشروط. قاعدة البيانات ترفض تاريخ الميلاد دون 18 سنة.
- ملف تدريجي محفوظ عند المتابعة، نية التعارف والاهتمامات وتفضيلات الجنس والعمر والظهور.
- اكتشاف مقسّم إلى صفحات مع استبعاد غير المتوافقين والمحظورين والمبلغ عنهم. عدد اهتمامات مشتركة حقيقي دون نسبة توافق مختلقة.
- إعجاب وتخطّي، ومطابقة متبادلة بمعاملة خادم، ودردشة نصية مستمرة مع Realtime ومقترح First Spark.
- حظر وإلغاء حظر وإبلاغ ودعم واستئناف وتصدير جزئي وحذف الحساب.
- بوابة إشراف على `/#/admin` لمراجعة البلاغات وتعليق الحساب، مع أدوار وتدقيق من الخادم. ليست لوحة مستقلة مكتملة.
- أساس قاعدة بيانات للاستحقاقات والأرصدة والمشتريات، ومعاملات خادم ومنع تكرار الأحداث. الدفع الفعلي معطّل.

## ما لم يُنفذ بعد

رفع الصور والصوت، الردود والتفاعلات وإيصالات القراءة والكتابة، التوثيق، الموقع والمسافة، المحفوظات والتراجع وMoments، إشعارات FCM، OTP وGoogle/Apple، عمليات الدفع والتحقق من المتاجر والاستعادة والاسترداد، مزايا الخطط المدفوعة، لوحة الإدارة الكاملة والتحليلات، تخزين جلسات الهاتف في Keychain/Keystore، واستكمال تدقيق الأمن والخصوصية. تقدم الإعداد محفوظ عند الضغط على المتابعة وليس عند كل كتابة. اختيار اللغة والمظهر لا يستمر بين مرات التشغيل بعد.

لا توجد بيانات Supabase أو Firebase أو متاجر مهيأة هنا. لم تُنفذ اختبارات خادم حي أو قاعدة بيانات محلية. راجع [الحالة التفصيلية](BUILD_STATUS.md) قبل اتخاذ قرار إطلاق.

## بنية الملفات

| المسار | الغرض |
|---|---|
| `lib/app` | الجلسة والتوجيه والمظهر والتنقل |
| `lib/core` | الإعدادات والترجمة والتحقق |
| `lib/features` | التسجيل والملف والاكتشاف والمحادثات والإشراف |
| `lib/shared` | مستودع Supabase وعناصر مشتركة وعقد الدفع |
| `supabase/migrations` | إنشاء الجداول والسياسات ودوال الأعمال |
| `supabase/tests` | 30 تحقق pgTAP، لم تُنفذ محليًا بعد |
| `test` | اختبارات Flutter المنفذة |
| `docs` | المعمارية والأمن والدفع والإشعارات والتشغيل ومسودات قانونية |

## التحقق والبناء

```text
dart format lib test
flutter analyze
flutter test
flutter build web --release
flutter build apk --debug
```

Flutter الحالي: 3.47.7، Dart: 3.13.5. الحزم مثبتة بإصدارات متاحة محليًا وملف lock. نجحت اختبارات Flutter الخمسة عشر وبناء الويب وAndroid التجريبي؛ التفاصيل والقيود في BUILD_STATUS. iOS يحتاج جهاز Mac والتوقيع. CI مُعد للتحليل والاختبارات وبناء الويب واختبارات Supabase المحلية، لكنه لم يُشغّل على GitHub بعد.

## قبل الإطلاق والربح

1. جهّز Supabase staging وSMTP، وشغّل اختبارات السياسات ثم اختبر الرحلة بهاتفين وحسابين حقيقيين، وأكمل الصور والسلامة.
2. أكمل مراجعة الأمن والخصوصية ولوحة الإشراف واحتفاظ البيانات، وثبّت العلامة ومعرفات المتاجر.
3. نفّذ مزايا مدفوعة حقيقية ثم تكامل المتاجر والتحقق من المدفوعات في sandbox، واختبر الاستعادة والاسترداد قبل أي تحصيل فعلي.
