# اختبار NOVA 0.3 ونشره

افتح [التطبيق](https://mohamedmohsenarabtec-bot.github.io/NOVA/) أو [المصدر](https://github.com/mohamedmohsenarabtec-bot/NOVA). هذه معاينة تطوير؛ الدفع والتجديد والتجربة المدفوعة ومكافآت الدعوات غير مفعلة. الأسعار بالجنيه المصري مقترحات توضيحية لم يعتمدها المالك.

## الاستخدام

من «حسابي» ترى اسمك وبريدك الخاص ونسبة اكتمال الملف والعضوية. «تعديل ملفي وصوري» يحفظ الحقول والصور فعليًا؛ اختر لكل صورة ظهورًا عامًا للملفات المسموح لها، أو للتطابقات، أو لنفسك فقط. يمكنك إخفاء الحقول الاختيارية. لا يُعرض البريد أو تاريخ الميلاد الكامل للآخرين.

الفلاتر تحفظ العمر والمدينة/المنطقة والنية والنوع. يعمل الاختيار اليدوي دون GPS. الفلاتر المتقدمة قائمة على استحقاق الخادم؛ لا يكفي تعديل واجهة Flutter للحصول عليها. المفضلة خاصة ولا ترسل إشعارًا. الإعجاب المعلق ينتهي بعد 48 ساعة، والتطابق يحتاج إعجاب الطرفين. المحادثة القائمة لا تنتهي تلقائيًا بعد 48 ساعة.

أيقونة الجرس تفتح إشعارات داخل التطبيق فقط. «من أعجبوا بي» يعرض عددًا حقيقيًا دون هويات لمستخدم Free، والهويات المسموح بها فقط عند امتلاك Premium حقيقي. لا يمكن شراء أو تفعيل Premium من هذه المعاينة. الدعوة تُحفظ عند إدخال الرمز الصحيح؛ فتح الرابط وحده لا يمنح مكافأة.

حساب المالك الموجود لم يُحذف أو تتغير كلمته. سجل دخوله المعتاد، ثم «حسابي ← تغيير كلمة المرور». بوابة الإدارة تظهر فقط للدور المخول؛ المسار المباشر /#/admin لا يمنح صلاحيات. لا ترسل كلمة المرور أو ملف الوصول المحلي لأحد. حسابا التطوير الموجودان محفوظان مستخدمين عاديين ومعزولان عن اكتشاف المستخدمين الحقيقيين. لا توجد كلمات مرور أو معرفات اختبار في التطبيق أو هذه الوثائق العامة.

اللغة والمظهر مشتركان بين جميع الشاشات، ويتبع النص والاتجاه الاختيار المحفوظ. زر الشمس/القمر يبدل المظهر، وقائمته توفر «النظام».

## الإعداد والاختبارات للمطور

Flutter 3.47.7 / Dart 3.13.5. انسخ config/local.example.json إلى config/local.json المحلي المستبعد من Git، وضع عنوان مشروع Supabase الأساسي والمفتاح العام فقط. لا تضع service-role أو كلمة مرور أو رمز CLI في Flutter.

```text
dart format .
flutter analyze
flutter test
flutter build web --release --base-href=/NOVA/ --dart-define-from-file=config/local.json
flutter build apk --release --dart-define-from-file=config/local.json
```

المخطط الحالي اثنا عشر ترحيلًا مرتبة. لا تشغّل db reset على مشروع المالك. افحص inspect_remote.sql ثم migration list وdb push --dry-run --linked. لا تطبق إلا الناقص بعد نجاح اختبارات قاعدة معزولة. بعد التطبيق نفّذ verify_remote.sql قراءة فقط. client_readiness=4 متعمد لحماية التطبيقات القديمة؛ client_capabilities=10 للإصدار الجديد.

دالة الصور الخادمية جزء لازم من النشر:

```text
supabase functions deploy profile-photo --project-ref <existing-project-ref> --use-api
```

تتحقق الدالة من جلسة Auth ثم RLS قبل إرسال البايتات، ولا تصدر رابطًا عامًا أو مفتاحًا خاصًا. CORS يسمح بأصل Pages الحالي وlocalhost:3000 فقط؛ أضف أصلًا مراجعًا عند تغيير الاستضافة. المفتاح الخادمي يبقى داخل بيئة Supabase.

اختبار قبول حي بلا كلمات مرور محفوظة:

```text
dart run scripts/live_iteration.dart config/local.json --browser-url=https://mohamedmohsenarabtec-bot.github.io/NOVA/
```

ينشئ حسابين خياليين جديدين بكلمات عشوائية في الذاكرة، ويعزلهما خادميًا قبل إكمال الملف، ويختبر الصور والخصوصية والتطابق وRealtime والحظر ثم يحذف فقط ما أنشأه. يحتاج CLI مخولًا لعزل الحسابين؛ لا يحذف الحسابات القديمة. النتائج المحلية الخالية من الأسرار في .local/iteration-live.json. للاختبار التطويري المستمر فقط، الخيار --retain-fictional يحتفظ بالحسابين الموسومين ويكتب وصولهما في .local/fictional-test-access.json المستبعد من Git. لا تستخدمه لملء اكتشاف الناس الحقيقيين. عند الإخفاق تُنظف الحسابات الجديدة حتى مع طلب الاحتفاظ.

الاختبارات المعزولة: supabase start ثم supabase test db؛ CI ينفذها بعيدًا عن بيانات المالك. لا تستخدم حسابات المالك كتركيبات اختبار.

## Android وiOS والنشر

كشف التشخيص فشل SharedPreferences في APK release قبل الاتصال بالشبكة: يصغّر R8 أسماء أصناف Kotlin التي تبحث عنها JNI بالاسم. أضيفت ست قواعد حفظ محددة من إصلاح Flutter الرسمي دون تعطيل التصغير. يعرض Flutter الآن أيضًا فورًا، بمهلة وإعادة محاولة، دون استهلاك مسار الدردشة العميق أثناء البداية. حالة هاتف Xiaomi الفعلية لم تُفحص عبر USB.

ملف APK: build/app/outputs/flutter-apk/app-release.apk. توقيعه الحالي شهادة Android Debug الأصلية للتجربة، وليس إصدار Play Store. احصل على رابط النسخة الجديدة وبصمتها ونتيجة تثبيتها من BUILD_STATUS.md وdocs/verification/iteration-0.3.json. لا تستخدم رابط إصدار 0.2 القديم لتقييم الإصلاح.

سير Android published APK installation ينزل نفس ملف الإصدار ويثبته على Android 35، ويحتفظ بصور البداية والسجل وحالة انقطاع الإنترنت. يتعطل المحاكي المحلي Windows قبل الإقلاع؛ لا يعد ذلك اختبار تثبيت للتطبيق.

Pages ينشر main فقط، بمسار /NOVA/، من متغيرات GitHub العامة SUPABASE_URL وSUPABASE_PUBLISHABLE_KEY. تحقق من نجاح workflow ثم build-info.json ومطابقة SHA مع main، ومن تحميل الصفحة وmain.dart.js وملفات الخطوط. لا يعني push وحده نجاح النشر.

iOS: أُضيف إذن اختيار الصور، والحد الأدنى 15.0. نجح سير macOS/Xcode رقم 39739210772 في بناء unsigned فعليًا. لم يختبر جهاز iPhone ولم يوقع الإصدار. المتجر يحتاج حساب Apple وتوقيعًا وProvisioning.

## إجراءات تشغيل لم تكتمل

عامل التنفيذ النهائي لطلبات الحذف بعد مهلة 7 أيام غير منفذ؛ الطلب والإلغاء والإخفاء محفوظة، ويجب على الإدارة معالجة الطلبات وفق السياسة. retention_maintenance إجراء خادمي مخول ولم يجدول تلقائيًا. مراجعة الإحالات ومنح المكافأة تحتاج مشغلًا مخولًا وقواعد معتمدة؛ الأزرار لا تمنح صلاحيات أو أرصدة. الدفع وPush والتوثيق الآلي وفحص محتوى الصور وإطلاق المتاجر مراحل لاحقة.
