# Notifications

Persistent in-app notifications are functional: transactional like/match/message events, verified membership/verification updates, granted referral rewards and lazy pending-expiry reminders. Unique event_key prevents duplication. Inbox is owner-only, paginated, and limited to the last 90 days; read-one/read-all and unread counts persist. Shared header badge polls every 40 seconds. Message previews contain no private body. Conversation references are rechecked against current chat authorization before returning.

Push is NOT implemented. No FCM/APNs credentials, worker or device delivery is asserted. Future integration needs per-environment Firebase/APNs/VAPID, informed opt-in, secure token registration, recipient/block/mute/category/quiet-hours checks, server credential storage, delivery/retry and device tests. Never send message bodies by default. Physical cleanup uses service-only retention_maintenance and still requires scheduling. Expiry reminders are created when relevant APIs are polled; no background reminder scheduler is deployed.
