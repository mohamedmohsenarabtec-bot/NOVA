# مسودة الاشتراكات والاسترداد — غير مفعلة

لم تُطرح اشتراكات أو أرصدة للبيع. الخطط المقترحة ليست وعدًا بمزايا متاحة. يبقى الحظر والإبلاغ وحماية الخصوصية متاحًا دون مقابل. التوثيق ليس للبيع.

قبل البيع يجب إدراج: السعر والعملة والضرائب والدورية والتجديد التلقائي والتجربة والإلغاء وإدارة الاشتراك والاستعادة وسياسة الاسترداد والقناة المناسبة لكل متجر ودولة. المدفوعات الرقمية على الهاتف تحتاج تكامل متجر متوافقًا مع القواعد السارية. [تُستكمل بمراجعة قانونية وتجارية ومراجعة سياسات المتاجر].
